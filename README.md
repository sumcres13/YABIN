# YABIN

Responsive bilingual website for Buddha Corporation and Yabin Indian Nepali Restaurant.

## Hosting

This is a static website. There is no install or build step. Point the host at the repository root and use `index.html` as the entry page. Keep the four HTML files, `styles.css`, `script.js`, and the `assets/` directory together so relative links and images continue to work.

For a local preview, run:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000/`.

Japanese line breaks are already included in the page content. Visitors do not need to run BudouX in their browser.
